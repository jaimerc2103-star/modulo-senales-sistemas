6.1 Introducción

En Señales y Sistemas, un sistema es un modelo matemático o físico que recibe una señal de entrada, realiza una transformación y produce una señal de salida.

El análisis de sistemas permite comprender cómo se modifican las señales al pasar por filtros, amplificadores, sensores, canales de comunicación, circuitos eléctricos, sistemas de control y algoritmos digitales.

6.2 Representación entrada-salida de un sistema

Un sistema puede estudiarse observando la relación entre la entrada y la salida.
Algunos ejemplos básicos son:
  • Amplificador: y(t) = 2x(t)
  • Atenuador: y(t) = 0.5x(t)
  • Retardador: y(t) = x(t - 1)
  • Derivador: y(t) = dx(t)/dt
  • Acumulador discreto: y[n] = suma acumulada de x[n]
En ingeniería, la representación entrada-salida permite describir un sistema sin necesariamente conocer todos sus detalles internos.

Ejemplo 1: Sistema amplificador continuo

clc;
clear;
close all;
 
t = 0:0.001:1;
x = sin(2*pi*5*t);
 
ganancia = 2;
y = ganancia*x;
 
figure;
plot(t,x,'LineWidth',1.5);
hold on;
plot(t,y,'--','LineWidth',1.5);
grid on;
xlabel('Tiempo t [s]');
ylabel('Amplitud');
title('Sistema amplificador: y(t) = 2x(t)');
legend('Entrada x(t)','Salida y(t)');

Interpretación del Ejemplo 1

El sistema multiplica la señal de entrada por una constante. La forma y la frecuencia de la señal no cambian, pero su amplitud se duplica.
Este modelo representa una etapa de ganancia o un amplificador ideal.

Interpretación de sistemas con memoria

La salida y[n] depende de la muestra actual x[n] y de la muestra anterior x[n-1]. Por tanto, el sistema necesita información previa de la señal y se clasifica como sistema con memoria.

Un sistema es causal si la salida en un instante depende únicamente de valores presentes o pasados de la entrada.

En sistemas físicos en tiempo real, la causalidad es indispensable porque no se puede conocer el futuro de una señal antes de que ocurra.

Ejemplo 5: Sistema causal y sistema no causal

clc;
clear;
close all;
 
n = 0:20;
x = double(n>=5 & n<=10);
 
x_pasada = [0 x(1:end-1)];
y_causal = x + x_pasada;
 
x_futura = [x(2:end) 0];
y_no_causal = x_futura;
 
figure;
 
subplot(3,1,1);
stem(n,x,'filled','LineWidth',1.2);
grid on;
title('Entrada x[n]');
xlabel('n');
ylabel('Amplitud');
 
subplot(3,1,2);
stem(n,y_causal,'filled','LineWidth',1.2);
grid on;
title('Sistema causal: y[n] = x[n] + x[n-1]');
xlabel('n');
ylabel('Amplitud');
 
subplot(3,1,3);
stem(n,y_no_causal,'filled','LineWidth',1.2);
grid on;
title('Sistema no causal: y[n] = x[n+1]');
xlabel('n');
ylabel('Amplitud');

Interpretación de causalidad

El sistema causal usa la muestra actual y una muestra pasada. Esto puede implementarse en tiempo real.
El sistema no causal requiere una muestra futura, por lo que no puede implementarse directamente en tiempo real sin conocer previamente toda la señal.

Interpretación de estabilidad

En el sistema estable, la salida permanece acotada porque solo se modifica la amplitud de la entrada.
En el sistema inestable, la salida crece debido al factor exponencial e^t. Aunque la entrada sinusoidal está acotada entre -1 y 1, la salida puede crecer indefinidamente.

clc;
clear;
close all;
 
t = 0:0.001:1;
 
x1 = sin(2*pi*3*t);
x2 = cos(2*pi*5*t);
 
T_lineal_suma = 2*(x1 + x2);
suma_salidas_lineal = 2*x1 + 2*x2;
 
T_nolineal_suma = (x1 + x2).^2;
suma_salidas_nolineal = x1.^2 + x2.^2;
 
figure;
 
subplot(2,1,1);
plot(t,T_lineal_suma,'LineWidth',1.4);
hold on;
plot(t,suma_salidas_lineal,'--','LineWidth',1.4);
grid on;
title('Sistema lineal: T{x_1+x_2} = T{x_1}+T{x_2}');
legend('T{x_1+x_2}','T{x_1}+T{x_2}');
 
subplot(2,1,2);
plot(t,T_nolineal_suma,'LineWidth',1.4);
hold on;
plot(t,suma_salidas_nolineal,'--','LineWidth',1.4);
grid on;
title('Sistema no lineal: T{x} = x^2');
legend('T{x_1+x_2}','T{x_1}+T{x_2}');
xlabel('Tiempo [s]');

Interpretación de linealidad

En el sistema lineal, aplicar el sistema a la suma de entradas produce el mismo resultado que sumar las salidas individuales.
En el sistema no lineal, esta igualdad no se cumple debido a la operación de elevar al cuadrado.

6.8 Sistemas invariantes y variantes en el tiempo

Un sistema es invariante en el tiempo si un desplazamiento en la entrada produce el mismo desplazamiento en la salida.
Si x(t) produce y(t), entonces x(t - t0) debe producir y(t - t0).

Ejemplo variante:
porque la salida depende explícitamente del tiempo t.

Ejemplo 9: Sistema invariante en el tiempo

clc;
clear;
close all;
 
t = 0:0.001:3;
 
x = sin(2*pi*2*t);
 
t0 = 0.5;
x_ret = sin(2*pi*2*(t-t0));
x_ret(t<t0) = 0;
 
y_ret_entrada = 2*x_ret;
 
y_ret_salida = 2*sin(2*pi*2*(t-t0));
y_ret_salida(t<t0) = 0;
 
figure;
plot(t,y_ret_entrada,'LineWidth',1.5);
hold on;
plot(t,y_ret_salida,'--','LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Sistema invariante en el tiempo');
legend('T{x(t-t0)}','y(t-t0)');

Ejemplo 10: Sistema variante en el tiempo

clc;
clear;
close all;
 
t = 0:0.001:3;
 
x = sin(2*pi*2*t);
 
t0 = 0.5;
x_ret = sin(2*pi*2*(t-t0));
x_ret(t<t0) = 0;
 
y_entrada_retardada = t.*x_ret;
 
t_shift = t - t0;
y_salida_retardada = t_shift.*sin(2*pi*2*t_shift);
y_salida_retardada(t<t0) = 0;
 
figure;
plot(t,y_entrada_retardada,'LineWidth',1.5);
hold on;
plot(t,y_salida_retardada,'--','LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Sistema variante en el tiempo');
legend('T{x(t-t0)}','y(t-t0)');

Interpretación de invariancia en el tiempo

En y(t) = 2x(t), retardar la entrada solo retarda la salida. Por eso, el sistema es invariante en el tiempo.
En y(t) = t x(t), la salida depende explícitamente del tiempo. Por ello, el sistema es variante en el tiempo.

6.9 Resumen de propiedades de sistemas

  • Sin memoria: la salida depende solo del valor actual de la entrada.
  • Con memoria: la salida depende de valores pasados o futuros.
  • Causal: depende de valores presentes o pasados.
  • No causal: depende de valores futuros.
  • Estable: entrada acotada produce salida acotada.
  • Inestable: entrada acotada puede producir salida no acotada.
  • Lineal: cumple superposición.
  • No lineal: no cumple superposición.
  • Invariante en el tiempo: un retardo en la entrada produce igual retardo en la salida.
  • Variante en el tiempo: sus propiedades dependen explícitamente del tiempo.

6.10 Aplicación en telecomunicaciones

En telecomunicaciones, un sistema puede representar un canal de comunicación, un amplificador, un filtro, un modulador, un conversor analógico-digital o un algoritmo de procesamiento digital.
Por ejemplo, un canal ideal con atenuación y retardo puede modelarse como:
y(t) = a x(t - t0)
donde a representa la atenuación y t0 representa el retardo de propagación.
Este sistema es lineal, causal si t0 > 0, estable e invariante en el tiempo.

Ejemplo 11: Canal de comunicación ideal con atenuación y retardo

clc;
clear;
close all;
 
t = 0:0.001:2;
 
x = sin(2*pi*5*t);
 
a = 0.6;
t0 = 0.25;
 
t_ret = t - t0;
x_ret = sin(2*pi*5*t_ret);
x_ret(t<t0) = 0;
 
y = a*x_ret;
 
figure;
 
subplot(2,1,1);
plot(t,x,'LineWidth',1.4);
grid on;
title('Señal transmitida x(t)');
xlabel('Tiempo [s]');
ylabel('Amplitud');
 
subplot(2,1,2);
plot(t,y,'LineWidth',1.4);
grid on;
title('Señal recibida y(t) = 0.6x(t - 0.25)');
xlabel('Tiempo [s]');
ylabel('Amplitud');

Interpretación del canal ideal

La señal recibida es una versión atenuada y retardada de la señal transmitida. Este modelo básico permite interpretar fenómenos de propagación, pérdidas en el canal y tiempo de llegada de una señal.

Conclusiones

Un sistema transforma una señal de entrada en una señal de salida. La clasificación de sistemas permite comprender cómo se comportará esta transformación y qué herramientas matemáticas pueden utilizarse para su análisis.
Las propiedades de memoria, causalidad, estabilidad, linealidad e invariancia en el tiempo son fundamentales para el estudio posterior de sistemas LTI y convolución.
MATLAB Live Script permite visualizar el comportamiento de diferentes sistemas mediante simulaciones, comparaciones gráficas e interpretación directa de entradas y salidas.
