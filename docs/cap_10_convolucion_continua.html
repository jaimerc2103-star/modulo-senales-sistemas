Capítulo 10. Convolución continua

Resultado de aprendizaje

Al finalizar este capítulo, el estudiante será capaz de interpretar, calcular y simular la convolución continua entre señales, relacionándola con la respuesta de sistemas LTI continuos y aplicándola a ejemplos de ingeniería mediante aproximaciones numéricas en MATLAB Live Script.

10.1 Introducción

La convolución continua es una operación fundamental para determinar la salida de un sistema lineal invariante en el tiempo cuando se conoce la señal de entrada x(t) y la respuesta al impulso h(t).
Para un sistema LTI continuo:
y(t) = x(t) * h(t)
donde:
  • x(t) es la señal de entrada.
  • h(t) es la respuesta al impulso del sistema.
  • y(t) es la señal de salida.
  • * representa la operación de convolución.
La convolución continua permite analizar circuitos, sistemas mecánicos, filtros analógicos, canales de comunicación, sistemas térmicos y modelos dinámicos de primer y segundo orden.

10.2 Definición matemática de convolución continua

La convolución continua entre dos señales x(t) y h(t) se define como:
y(t) = integral desde -infinito hasta infinito de x(tau) h(t - tau) d tau
donde tau es una variable auxiliar de integración.
Esta integral indica que, para cada valor de t, se realiza una superposición entre x(tau) y una versión reflejada y desplazada de h(tau).
El procedimiento gráfico general es:
1. Tomar una de las señales. 2. Reflejarla respecto al eje vertical. 3. Desplazarla en el tiempo. 4. Multiplicar punto a punto. 5. Integrar el área del producto.
Aunque el cálculo analítico puede ser complejo, MATLAB permite aproximar la convolución continua usando discretización temporal.

10.3 Aproximación numérica de la convolución continua

MATLAB trabaja con vectores discretos. Por ello, para aproximar una convolución continua, se define un paso de tiempo pequeño dt y se utiliza:
y(t) aproximadamente igual a conv(x,h)*dt
El factor dt es necesario porque la convolución continua implica una integral, y una integral numérica se aproxima mediante sumas multiplicadas por el paso de integración.
Si no se multiplica por dt, la amplitud del resultado no representa adecuadamente la integral continua.

Ejemplo 1: Convolución continua aproximada entre dos pulsos rectangulares

clc;
clear;
close all;
 
% Vector de tiempo
dt = 0.001;
t = -2:dt:2;
 
% Pulso rectangular x(t): activo entre 0 y 1
x = double(t >= 0 & t <= 1);
 
% Pulso rectangular h(t): activo entre 0 y 1
h = double(t >= 0 & t <= 1);
 
% Convolución aproximada
y = conv(x,h)*dt;
 
% Eje temporal de la convolución
ty = (2*t(1)):dt:(2*t(end));
 
% Gráfica
figure;
 
subplot(3,1,1);
plot(t,x,'LineWidth',1.5);
grid on;
xlabel('Tiempo t [s]');
ylabel('x(t)');
title('Señal x(t): pulso rectangular');
 
subplot(3,1,2);
plot(t,h,'LineWidth',1.5);
grid on;
xlabel('Tiempo t [s]');
ylabel('h(t)');
title('Señal h(t): pulso rectangular');
 
subplot(3,1,3);
plot(ty,y,'LineWidth',1.5);
grid on;
xlabel('Tiempo t [s]');
ylabel('y(t)');
title('Convolución continua aproximada y(t) = x(t) * h(t)');

Interpretación del Ejemplo 1

La convolución de dos pulsos rectangulares iguales genera una señal triangular.
Esto ocurre porque, a medida que un pulso se desplaza sobre el otro, el área de solapamiento aumenta linealmente, alcanza un máximo y luego disminuye linealmente.
Este resultado es clásico y permite comprender la interpretación geométrica de la convolución continua como área de superposición.

10.4 Convolución entre escalón y exponencial

En sistemas de primer orden, una respuesta al impulso común es:
h(t) = e^(-at)u(t)
Si la entrada es un escalón unitario:
x(t) = u(t)
la salida del sistema representa la respuesta al escalón.
Esta situación aparece en circuitos RC, procesos térmicos y sistemas dinámicos de primer orden.

Ejemplo 2: Convolución entre escalón unitario y exponencial decreciente

clc;
clear;
close all;
 
dt = 0.001;
t = -1:dt:8;
 
% Señal escalón
u = double(t >= 0);
x = u;
 
% Respuesta al impulso h(t) = exp(-at)u(t)
a = 1;
h = exp(-a*t).*u;
 
% Convolución aproximada
y = conv(x,h)*dt;
ty = (2*t(1)):dt:(2*t(end));
 
figure;
 
subplot(3,1,1);
plot(t,x,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('x(t)');
title('Entrada x(t) = u(t)');
 
subplot(3,1,2);
plot(t,h,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('h(t)');
title('Respuesta al impulso h(t) = e^{-t}u(t)');
 
subplot(3,1,3);
plot(ty,y,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('y(t)');
title('Respuesta al escalón y(t) = u(t) * e^{-t}u(t)');
xlim([-1 8]);

Interpretación del Ejemplo 2

La salida aumenta gradualmente hasta aproximarse a un valor constante.
Este comportamiento corresponde a la respuesta de un sistema de primer orden ante una entrada tipo escalón. En un circuito RC, por ejemplo, puede representar la carga progresiva de un capacitor.
Para h(t)=e^{-t}u(t), la respuesta al escalón ideal es:
y(t) = (1 - e^{-t})u(t)

10.5 Comparación con solución analítica

Para el caso:
x(t) = u(t)
h(t) = e^{-t}u(t)
la convolución analítica es:
y(t) = (1 - e^{-t})u(t)
Se puede comparar la aproximación numérica con la expresión analítica.

Ejemplo 3: Comparación entre convolución numérica y solución analítica

clc;
clear;
close all;
 
dt = 0.001;
t = -1:dt:8;
 
u = double(t >= 0);
x = u;
h = exp(-t).*u;
 
% Convolución numérica
y_num = conv(x,h)*dt;
ty = (2*t(1)):dt:(2*t(end));
 
% Solución analítica evaluada sobre ty
u_y = double(ty >= 0);
y_analitica = (1 - exp(-ty)).*u_y;
 
figure;
plot(ty,y_num,'LineWidth',1.5);
hold on;
plot(ty,y_analitica,'--','LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Comparación entre convolución numérica y solución analítica');
legend('Convolución numérica','Solución analítica');
xlim([-1 8]);

Interpretación del Ejemplo 3

La convolución numérica se aproxima a la solución analítica.
Las pequeñas diferencias pueden depender del paso de integración dt y de la longitud temporal usada para representar las señales.
Mientras menor sea dt, mejor será la aproximación numérica, aunque aumentará el costo computacional.

10.6 Convolución de exponenciales decrecientes

Considere:
x(t) = e^(-at)u(t)
h(t) = e^(-bt)u(t)
La convolución de dos exponenciales decrecientes genera una respuesta que depende de los parámetros a y b.
Este tipo de análisis aparece en sistemas en cascada de primer orden.

Ejemplo 4: Convolución de dos exponenciales decrecientes

clc;
clear;
close all;
 
dt = 0.001;
t = -1:dt:10;
 
u = double(t >= 0);
 
a = 1;
b = 2;
 
x = exp(-a*t).*u;
h = exp(-b*t).*u;
 
y = conv(x,h)*dt;
ty = (2*t(1)):dt:(2*t(end));
 
figure;
 
subplot(3,1,1);
plot(t,x,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('x(t)');
title('x(t) = e^{-t}u(t)');
 
subplot(3,1,2);
plot(t,h,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('h(t)');
title('h(t) = e^{-2t}u(t)');
 
subplot(3,1,3);
plot(ty,y,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('y(t)');
title('Convolución de dos exponenciales decrecientes');
xlim([-1 10]);

Interpretación del Ejemplo 4

La salida inicia en cero, aumenta hasta un máximo y luego decrece hacia cero.
Este comportamiento es típico cuando se combinan dos sistemas de primer orden en cascada. La señal resultante refleja la acumulación y posterior disipación de energía en el sistema.

10.7 Propiedades de la convolución continua

La convolución continua posee propiedades similares a la convolución discreta:
1. Conmutativa:
x(t) * h(t) = h(t) * x(t)
2. Asociativa:
x(t) * [h1(t) * h2(t)] = [x(t) * h1(t)] * h2(t)
3. Distributiva:
x(t) * [h1(t) + h2(t)] = x(t) * h1(t) + x(t) * h2(t)
4. Identidad:
x(t) * delta(t) = x(t)
Estas propiedades son fundamentales para analizar sistemas LTI continuos, especialmente cuando existen sistemas conectados en serie o paralelo.

Ejemplo 5: Propiedad conmutativa en convolución continua aproximada

clc;
clear;
close all;
 
dt = 0.001;
t = -1:dt:5;
 
u = double(t >= 0);
 
x = exp(-t).*u;
h = double(t >= 0 & t <= 1);
 
y1 = conv(x,h)*dt;
y2 = conv(h,x)*dt;
 
ty = (2*t(1)):dt:(2*t(end));
 
figure;
plot(ty,y1,'LineWidth',1.5);
hold on;
plot(ty,y2,'--','LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Propiedad conmutativa de la convolución continua');
legend('x(t)*h(t)','h(t)*x(t)');
xlim([-1 6]);

Interpretación del Ejemplo 5

Las dos convoluciones coinciden, lo que confirma la propiedad conmutativa.
Aunque la interpretación física suele considerar x(t) como entrada y h(t) como respuesta del sistema, matemáticamente el orden de la convolución no altera el resultado.

10.8 Convolución continua y sistemas LTI

En un sistema LTI continuo, la respuesta al impulso h(t) caracteriza el sistema.
Para cualquier entrada x(t), la salida es:
y(t) = x(t) * h(t)
Esta relación permite analizar sistemas eléctricos, mecánicos, térmicos y de comunicación.
Si h(t) es estable y causal, el sistema puede representar muchos procesos físicos reales.

Ejemplo 6: Sistema LTI continuo con respuesta al impulso exponencial

clc;
clear;
close all;
 
dt = 0.001;
t = -1:dt:8;
 
u = double(t >= 0);
 
% Entrada: pulso rectangular
x = double(t >= 0 & t <= 2);
 
% Respuesta al impulso del sistema
h = exp(-1.5*t).*u;
 
% Salida
y = conv(x,h)*dt;
ty = (2*t(1)):dt:(2*t(end));
 
figure;
 
subplot(3,1,1);
plot(t,x,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('x(t)');
title('Entrada: pulso rectangular');
 
subplot(3,1,2);
plot(t,h,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('h(t)');
title('Respuesta al impulso: h(t)=e^{-1.5t}u(t)');
 
subplot(3,1,3);
plot(ty,y,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('y(t)');
title('Salida del sistema LTI y(t)=x(t)*h(t)');
xlim([-1 8]);

Interpretación del Ejemplo 6

La salida representa la respuesta del sistema ante una entrada rectangular.
Durante el pulso de entrada, el sistema acumula respuesta. Cuando el pulso termina, la salida decrece debido a la dinámica exponencial de h(t).
Este comportamiento aparece en circuitos RC, sistemas térmicos y modelos de amortiguamiento.

10.9 Convolución y respuesta al escalón

La respuesta al escalón de un sistema LTI se obtiene convolucionando el escalón unitario con la respuesta al impulso:
s(t) = u(t) * h(t)
Si h(t) es la respuesta al impulso, s(t) representa cómo responde el sistema ante una entrada que se activa en t = 0 y permanece constante.

Ejemplo 7: Respuesta al escalón de un sistema de primer orden

clc;
clear;
close all;
 
dt = 0.001;
t = -1:dt:8;
 
u = double(t >= 0);
 
% Respuesta al impulso
a = 2;
h = a*exp(-a*t).*u;
 
% Entrada escalón
x = u;
 
% Respuesta al escalón
s = conv(x,h)*dt;
ts = (2*t(1)):dt:(2*t(end));
 
figure;
 
subplot(3,1,1);
plot(t,x,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('u(t)');
title('Entrada escalón');
 
subplot(3,1,2);
plot(t,h,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('h(t)');
title('Respuesta al impulso h(t)=ae^{-at}u(t)');
 
subplot(3,1,3);
plot(ts,s,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('s(t)');
title('Respuesta al escalón s(t)=u(t)*h(t)');
xlim([-1 8]);

Interpretación del Ejemplo 7

La respuesta al escalón crece gradualmente hasta aproximarse a un valor final. Este valor final depende de la ganancia del sistema.
En este ejemplo, la respuesta al impulso está normalizada para que el valor final de la respuesta al escalón sea aproximadamente 1.

10.10 Convolución y canales de comunicación continuos

En comunicaciones, un canal puede modelarse mediante su respuesta al impulso h(t).
Si la señal transmitida es x(t), la señal recibida ideal sin ruido es:
y(t) = x(t) * h(t)
Un canal con eco puede tener una respuesta:
h(t) = delta(t) + a delta(t - t0)
Esto significa que el receptor recibe una copia directa y una copia retardada de menor amplitud.
En MATLAB, se puede aproximar el efecto usando señales discretizadas.

Ejemplo 8: Canal continuo aproximado con eco

clc;
clear;
close all;
 
dt = 0.001;
t = 0:dt:2;
 
% Señal transmitida
x = sin(2*pi*5*t).*(t <= 1);
 
% Respuesta del canal aproximada
h = zeros(size(t));
h(1) = 1/dt; % impulso aproximado en t = 0
retardo = 0.3;
indice_retardo = round(retardo/dt) + 1;
h(indice_retardo) = 0.5/dt; % eco retardado
 
% Señal recibida aproximada
y = conv(x,h)*dt;
ty = 0:dt:(length(y)-1)*dt;
 
figure;
 
subplot(3,1,1);
plot(t,x,'LineWidth',1.4);
grid on;
xlabel('Tiempo [s]');
ylabel('x(t)');
title('Señal transmitida');
 
subplot(3,1,2);
plot(t,h,'LineWidth',1.2);
grid on;
xlabel('Tiempo [s]');
ylabel('h(t)');
title('Respuesta del canal con eco aproximado');
xlim([0 1]);
 
subplot(3,1,3);
plot(ty,y,'LineWidth',1.4);
grid on;
xlabel('Tiempo [s]');
ylabel('y(t)');
title('Señal recibida con eco');
xlim([0 2]);

Interpretación del Ejemplo 8

La señal recibida contiene la señal original y una copia retardada de menor amplitud. Este fenómeno puede interpretarse como eco o multitrayectoria.
En comunicaciones inalámbricas, las reflexiones en edificios, paredes, vehículos o montañas pueden producir múltiples copias retardadas de una señal.

10.11 Importancia del paso de tiempo dt

Al aproximar una convolución continua en MATLAB, el valor de dt es muy importante.
Si dt es grande, la aproximación puede ser poco precisa.
Si dt es pequeño, la aproximación mejora, pero aumenta el número de muestras y el costo computacional.
La multiplicación por dt después de conv es necesaria para aproximar la integral de convolución continua.

Ejemplo 9: Efecto del paso de tiempo en la convolución

clc;
clear;
close all;
 
% Primer paso de tiempo
dt1 = 0.01;
t1 = 0:dt1:5;
x1 = exp(-t1);
h1 = exp(-2*t1);
y1 = conv(x1,h1)*dt1;
ty1 = 0:dt1:(length(y1)-1)*dt1;
 
% Segundo paso de tiempo
dt2 = 0.001;
t2 = 0:dt2:5;
x2 = exp(-t2);
h2 = exp(-2*t2);
y2 = conv(x2,h2)*dt2;
ty2 = 0:dt2:(length(y2)-1)*dt2;
 
figure;
plot(ty1,y1,'LineWidth',1.5);
hold on;
plot(ty2,y2,'--','LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Efecto del paso de tiempo dt en la convolución numérica');
legend('dt = 0.01','dt = 0.001');
xlim([0 5]);

Interpretación del Ejemplo 9

Las dos aproximaciones son similares, pero la de menor dt representa mejor la integral continua.
En problemas de simulación, se debe elegir un dt suficientemente pequeño para obtener precisión sin hacer el cálculo innecesariamente pesado.

10.12 Resumen conceptual

La convolución continua permite calcular la salida de sistemas LTI continuos.
Ideas clave:
  • La convolución continua se define mediante una integral.
  • En MATLAB se aproxima usando conv(x,h)*dt.
  • La respuesta al impulso h(t) caracteriza al sistema LTI.
  • La respuesta al escalón se obtiene como u(t)*h(t).
  • La convolución de pulsos rectangulares puede producir señales triangulares.
  • La convolución permite modelar circuitos, filtros, sistemas térmicos, sistemas mecánicos y canales de comunicación.
La convolución continua conecta el análisis temporal de señales con la respuesta dinámica de sistemas reales.

Conclusiones

La convolución continua es una herramienta fundamental para calcular la salida de sistemas LTI continuos. A diferencia de la convolución discreta, se define mediante una integral, pero puede aproximarse numéricamente en MATLAB usando vectores y la función conv multiplicada por dt.
La respuesta al impulso h(t) caracteriza completamente el sistema LTI y permite analizar la salida ante diferentes entradas. Esta propiedad se aplica en circuitos, filtros analógicos, sistemas térmicos, sistemas mecánicos y canales de comunicación.
MATLAB Live Script permite visualizar la convolución continua, comparar aproximaciones numéricas con soluciones analíticas y comprender la relación entre señales, sistemas y respuesta temporal.
