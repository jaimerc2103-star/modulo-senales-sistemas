Capítulo 8. Respuesta al impulso

Resultado de aprendizaje

Al finalizar este capítulo, el estudiante será capaz de interpretar la respuesta al impulso como la característica fundamental de un sistema LTI, representarla en tiempo continuo y discreto, y analizar su relación con la salida del sistema mediante ejemplos desarrollados en MATLAB Live Script.

8.1 Introducción

En los sistemas lineales invariantes en el tiempo, la respuesta al impulso es una herramienta esencial. Permite conocer cómo responde un sistema ante una entrada elemental concentrada en un instante.
En tiempo discreto, el impulso unitario se representa como:
delta[n]
En tiempo continuo, se utiliza el impulso de Dirac:
delta(t)
La respuesta al impulso se representa como:
h(t)
para sistemas continuos, o:
h[n]
para sistemas discretos.
La importancia de la respuesta al impulso radica en que, si se conoce h(t) o h[n], se puede determinar la salida del sistema para cualquier entrada mediante la operación de convolución.
Para un sistema LTI:
y(t) = x(t) * h(t)
o en tiempo discreto:
y[n] = x[n] * h[n]
donde * representa convolución.

8.2 Concepto de impulso unitario discreto

En tiempo discreto, el impulso unitario se define como:
delta[n] = 1, si n = 0
delta[n] = 0, si n distinto de 0
Esta señal es fundamental porque permite representar cualquier secuencia discreta como una suma ponderada de impulsos desplazados.
Por ejemplo, una secuencia x[n] puede expresarse como:
x[n] = suma de x[k] delta[n-k]
Esta propiedad permite analizar los sistemas LTI a partir de su respuesta ante impulsos desplazados.

Ejemplo 1: Impulso unitario discreto

clc;
clear;
close all;
 
n = -10:10;
delta = double(n == 0);
 
figure;
stem(n, delta, 'filled', 'LineWidth', 1.3);
grid on;
xlabel('Índice n');
ylabel('Amplitud');
title('Impulso unitario discreto delta[n]');
ylim([-0.2 1.2]);

Interpretación del Ejemplo 1

El impulso unitario discreto tiene valor 1 únicamente en n = 0. Esta señal se usa como entrada de prueba para determinar la respuesta al impulso de un sistema discreto.
Si un sistema LTI recibe delta[n] como entrada, la salida obtenida se llama respuesta al impulso h[n].

8.3 Respuesta al impulso de un sistema discreto

Para un sistema discreto LTI, la respuesta al impulso h[n] es la salida que se obtiene cuando la entrada es delta[n].
Si:
x[n] = delta[n]
entonces:
y[n] = h[n]
Por ejemplo, considere el sistema:
y[n] = 0.5x[n] + 0.5x[n-1]
Si la entrada es delta[n], la salida será:
h[n] = 0.5delta[n] + 0.5delta[n-1]
Esto significa que la respuesta al impulso tiene dos muestras no nulas.

Ejemplo 2: Respuesta al impulso de un sistema discreto simple

clc;
clear;
close all;
 
n = 0:20;
 
% Entrada impulso
delta = double(n == 0);
 
% Sistema: y[n] = 0.5x[n] + 0.5x[n-1]
x_pasada = [0 delta(1:end-1)];
h = 0.5*delta + 0.5*x_pasada;
 
figure;
 
subplot(2,1,1);
stem(n, delta, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Entrada delta[n]');
 
subplot(2,1,2);
stem(n, h, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Respuesta al impulso h[n]');

Interpretación del Ejemplo 2

La salida ante el impulso unitario corresponde a la respuesta al impulso del sistema.
En este caso, h[n] tiene dos valores principales: uno en n = 0 y otro en n = 1. Esto indica que el sistema combina la muestra actual y la muestra anterior de la entrada.
Este tipo de respuesta es característica de un filtro digital de promedio simple.

8.4 Respuesta al impulso y sistemas LTI

En un sistema LTI, la respuesta al impulso permite caracterizar completamente el sistema.
Esto se debe a dos propiedades:
1. Linealidad:
Si una entrada puede expresarse como suma de impulsos ponderados, la salida será la suma de las respuestas correspondientes.
2. Invariancia en el tiempo:
Si un impulso se desplaza, la respuesta al impulso también se desplaza en la misma cantidad.
Por tanto, conocer h[n] permite construir la salida para cualquier entrada x[n].

Ejemplo 3: Impulso desplazado y respuesta desplazada

clc;
clear;
close all;
 
n = 0:20;
 
% Impulso desplazado
n0 = 5;
delta_desplazado = double(n == n0);
 
% Sistema: y[n] = 0.5x[n] + 0.5x[n-1]
x_pasada = [0 delta_desplazado(1:end-1)];
y = 0.5*delta_desplazado + 0.5*x_pasada;
 
figure;
 
subplot(2,1,1);
stem(n, delta_desplazado, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Entrada delta[n-5]');
 
subplot(2,1,2);
stem(n, y, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Salida ante entrada desplazada');

Interpretación del Ejemplo 3

Cuando el impulso de entrada se desplaza a n = 5, la respuesta del sistema también se desplaza.
Esta propiedad es consecuencia directa de la invariancia en el tiempo. Si el sistema no fuera invariante, la respuesta no sería simplemente una versión desplazada.

8.5 Representación de una señal mediante impulsos

Cualquier señal discreta puede representarse como una suma de impulsos desplazados y ponderados.
Por ejemplo, si:
x[0] = 2
x[1] = -1
x[2] = 3
entonces puede escribirse como:
x[n] = 2delta[n] - delta[n-1] + 3delta[n-2]
Esta representación es importante porque permite comprender cómo un sistema LTI responde a cualquier señal discreta.

Ejemplo 4: Construcción de una señal con impulsos desplazados

clc;
clear;
close all;
 
n = 0:10;
 
% Secuencia original
x = zeros(size(n));
x(n==0) = 2;
x(n==1) = -1;
x(n==2) = 3;
 
% Construcción mediante impulsos
delta0 = double(n == 0);
delta1 = double(n == 1);
delta2 = double(n == 2);
 
x_impulsos = 2*delta0 - 1*delta1 + 3*delta2;
 
figure;
 
subplot(2,1,1);
stem(n, x, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Secuencia original x[n]');
 
subplot(2,1,2);
stem(n, x_impulsos, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Representación con impulsos desplazados');

Interpretación del Ejemplo 4

La secuencia se puede construir mediante impulsos desplazados con diferentes pesos.
Esta idea es la base conceptual para entender la convolución discreta, ya que la salida de un sistema LTI se puede obtener sumando respuestas al impulso desplazadas y ponderadas.

8.6 Respuesta de un sistema LTI ante una señal discreta

Si se conoce la respuesta al impulso h[n], la salida ante una entrada x[n] se puede obtener como una combinación de respuestas desplazadas.
Para una entrada compuesta por impulsos ponderados, cada impulso genera una respuesta h[n] desplazada y multiplicada por el valor correspondiente de la entrada.
La suma de todas esas respuestas produce la salida total del sistema.

Ejemplo 5: Respuesta de un sistema LTI usando impulsos ponderados

clc;
clear;
close all;
 
n = 0:10;
 
% Entrada x[n] = 2delta[n] - delta[n-1] + 3delta[n-2]
x = zeros(size(n));
x(n==0) = 2;
x(n==1) = -1;
x(n==2) = 3;
 
% Respuesta al impulso del sistema
h = zeros(size(n));
h(n==0) = 0.5;
h(n==1) = 0.5;
 
% Convolución manual con conv
y = conv(x, h);
ny = 0:length(y)-1;
 
figure;
 
subplot(3,1,1);
stem(n, x, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Entrada x[n]');
 
subplot(3,1,2);
stem(n, h, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Respuesta al impulso h[n]');
 
subplot(3,1,3);
stem(ny, y, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Salida y[n] = x[n] * h[n]');

Interpretación del Ejemplo 5

La salida del sistema se obtiene combinando la entrada con la respuesta al impulso.
Aunque aquí se usa la función conv de MATLAB, el resultado representa la suma de respuestas al impulso desplazadas y ponderadas.
Esta es la idea central de la convolución discreta.

8.7 Respuesta al impulso en tiempo continuo

En tiempo continuo, la respuesta al impulso h(t) es la salida del sistema cuando la entrada es el impulso de Dirac delta(t).
Aunque el impulso de Dirac no puede representarse como una función ordinaria en MATLAB, se puede analizar conceptualmente y aproximar mediante pulsos muy estrechos.
En sistemas físicos, h(t) describe cómo responde el sistema ante una entrada instantánea ideal.
Por ejemplo, un sistema de primer orden puede tener una respuesta al impulso de la forma:
h(t) = exp(-at)u(t)
donde a > 0.

Ejemplo 6: Respuesta al impulso continua de un sistema de primer orden

clc;
clear;
close all;
 
t = -1:0.001:6;
a = 1.2;
 
% Escalón unitario
u = double(t >= 0);
 
% Respuesta al impulso
h = exp(-a*t).*u;
 
figure;
plot(t, h, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo t [s]');
ylabel('Amplitud');
title('Respuesta al impulso continua h(t) = e^{-at}u(t)');

Interpretación del Ejemplo 6

La respuesta al impulso inicia en t = 0 y decrece exponencialmente.
Este comportamiento aparece en sistemas de primer orden, como circuitos RC, procesos térmicos, sistemas mecánicos amortiguados y ciertos modelos de filtrado.
La forma de h(t) revela cómo el sistema disipa o atenúa una excitación instantánea.

8.8 Respuesta al impulso y estabilidad

En sistemas LTI, la estabilidad está relacionada con la respuesta al impulso.
En tiempo discreto, un sistema LTI es estable si:
suma de h[n] es finita
En tiempo continuo, un sistema LTI es estable si:
integral de h(t) dt es finita
Esto significa que la respuesta al impulso debe ser absolutamente integrable o absolutamente sumable.
Si la respuesta al impulso crece indefinidamente, el sistema puede ser inestable.

Ejemplo 7: Respuesta al impulso estable e inestable

clc;
clear;
close all;
 
t = 0:0.001:5;
 
% Respuesta estable
h_estable = exp(-t);
 
% Respuesta inestable
h_inestable = exp(t);
 
figure;
 
subplot(2,1,1);
plot(t, h_estable, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Respuesta al impulso estable h(t)=e^{-t}u(t)');
 
subplot(2,1,2);
plot(t, h_inestable, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Respuesta al impulso inestable h(t)=e^{t}u(t)');

Interpretación del Ejemplo 7

La respuesta h(t)=e^{-t}u(t) decrece hacia cero, por lo que está asociada a un sistema estable.
La respuesta h(t)=e^{t}u(t) crece con el tiempo, por lo que puede producir salidas no acotadas. Esto corresponde a un sistema inestable.

8.9 Respuesta al impulso y filtros digitales

En procesamiento digital de señales, un filtro puede describirse por su respuesta al impulso.
Un filtro de promedio móvil de tres muestras se puede definir como:
y[n] = (1/3)x[n] + (1/3)x[n-1] + (1/3)x[n-2]
Su respuesta al impulso es:
h[n] = (1/3)delta[n] + (1/3)delta[n-1] + (1/3)delta[n-2]
Este filtro suaviza la señal de entrada.

Ejemplo 8: Respuesta al impulso de un filtro promedio móvil

clc;
clear;
close all;
 
n = 0:20;
 
% Impulso unitario
delta = double(n == 0);
 
% Filtro promedio móvil de 3 muestras
x1 = delta;
x2 = [0 delta(1:end-1)];
x3 = [0 0 delta(1:end-2)];
 
h = (1/3)*x1 + (1/3)*x2 + (1/3)*x3;
 
figure;
 
subplot(2,1,1);
stem(n, delta, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Entrada impulso delta[n]');
 
subplot(2,1,2);
stem(n, h, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Respuesta al impulso del filtro promedio móvil');

Interpretación del Ejemplo 8

La respuesta al impulso del filtro tiene tres muestras iguales. Esto indica que el filtro promedia tres valores consecutivos de la entrada.
En señales con ruido, este tipo de filtro puede reducir variaciones rápidas, aunque también puede suavizar detalles de la señal.

8.10 Aplicación: suavizado de una señal con ruido

Conociendo la respuesta al impulso de un filtro, se puede aplicar el sistema a una señal de entrada mediante convolución.
En este ejemplo se aplica un filtro promedio móvil a una señal con ruido.

Ejemplo 9: Aplicación de un filtro usando respuesta al impulso

clc;
clear;
close all;
 
n = 0:80;
 
% Señal de entrada con ruido
rng(5);
x = sin(pi*n/10) + 0.4*randn(size(n));
 
% Respuesta al impulso del filtro promedio móvil
h = [1/3 1/3 1/3];
 
% Salida por convolución
y = conv(x, h, 'same');
 
figure;
 
subplot(2,1,1);
stem(n, x, 'filled', 'LineWidth', 1.0);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Señal discreta de entrada con ruido');
 
subplot(2,1,2);
stem(n, y, 'filled', 'LineWidth', 1.0);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Salida filtrada mediante respuesta al impulso h[n]');

Interpretación del Ejemplo 9

La salida es una versión suavizada de la señal de entrada.
El filtro promedio móvil reduce parte del ruido de alta variación, aunque puede modificar ligeramente la forma de la señal original.
Este ejemplo muestra cómo la respuesta al impulso se utiliza directamente para implementar filtros digitales.

8.11 Aplicación en telecomunicaciones

En telecomunicaciones, la respuesta al impulso permite modelar canales de transmisión.
Un canal ideal sin distorsión puede tener una respuesta:
h(t) = a delta(t - t0)
donde:
  • a representa la atenuación.
  • t0 representa el retardo de propagación.
Un canal con múltiples trayectorias puede representarse como:
h(t) = a1 delta(t - t1) + a2 delta(t - t2) + a3 delta(t - t3)
Esto permite modelar reflexiones, ecos y propagación multitrayectoria.

Ejemplo 10: Canal discreto con multitrayectoria

clc;
clear;
close all;
 
n = 0:30;
 
% Respuesta al impulso de un canal discreto
h = zeros(size(n));
h(n==0) = 1.0;
h(n==4) = 0.5;
h(n==8) = 0.25;
 
figure;
stem(n, h, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Respuesta al impulso de un canal con multitrayectoria');

Interpretación del Ejemplo 10

La respuesta al impulso tiene varios impulsos desplazados. Cada impulso representa una trayectoria de propagación distinta.
El primer impulso corresponde a la trayectoria directa. Los impulsos posteriores pueden representar reflexiones o ecos.
Este modelo es importante en comunicaciones inalámbricas, enlaces de radio, fibra óptica con reflexiones y transmisión en ambientes urbanos.

8.12 Resumen conceptual

La respuesta al impulso es la salida del sistema cuando la entrada es un impulso unitario.
En sistemas LTI, h(t) o h[n] caracteriza completamente el sistema.
Si se conoce la respuesta al impulso:
  • Se puede determinar la salida ante cualquier entrada.
  • Se puede analizar la estabilidad del sistema.
  • Se pueden estudiar filtros y canales de comunicación.
  • Se puede aplicar la operación de convolución.
La respuesta al impulso conecta directamente los conceptos de sistemas LTI y convolución.

Conclusiones

La respuesta al impulso es una herramienta central en el análisis de sistemas LTI. Permite caracterizar completamente el sistema y calcular su salida ante cualquier entrada mediante convolución.
En tiempo discreto, la respuesta al impulso puede obtenerse aplicando delta[n] como entrada. En tiempo continuo, h(t) representa la respuesta ante el impulso ideal de Dirac.
En aplicaciones de ingeniería, la respuesta al impulso se utiliza para analizar filtros, canales de comunicación, sistemas dinámicos, ecos, multitrayectoria, estabilidad y procesamiento digital de señales.
MATLAB Live Script permite visualizar estos conceptos y conectar la teoría con aplicaciones prácticas en telecomunicaciones, electrónica y análisis de sistemas.
