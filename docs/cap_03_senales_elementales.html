Capítulo 3. Señales elementales continuas y discretas

Resultado de aprendizaje

Al finalizar este capítulo, el estudiante será capaz de identificar, representar y analizar señales elementales continuas y discretas, tales como impulso, escalón, rampa, exponenciales y sinusoidales, utilizando MATLAB Live Script como herramienta de simulación y visualización.

3.1 Introducción

Las señales elementales constituyen la base para el análisis de señales y sistemas. Muchas señales complejas pueden construirse, aproximarse o estudiarse a partir de señales básicas como el impulso, el escalón, la rampa, las exponenciales y las sinusoidales.
Estas señales son importantes porque aparecen de manera recurrente en telecomunicaciones, circuitos eléctricos, sistemas de control, procesamiento digital de señales, sensores, audio, instrumentación y modelos dinámicos.
En este capítulo se estudiarán:
  • Impulso unitario.
  • Escalón unitario.
  • Rampa unitaria.
  • Señales exponenciales reales.
  • Señales exponenciales discretas.
  • Señales sinusoidales.
  • Señales rectangulares.
  • Señales triangulares.

3.2 Señal impulso unitario

En tiempo discreto, el impulso unitario se define como una señal que vale 1 en n = 0 y 0 en cualquier otro índice.
Esta señal es fundamental porque permite representar secuencias discretas como combinación de impulsos desplazados. Además, en sistemas LTI, la respuesta al impulso caracteriza completamente el comportamiento del sistema.

Ejemplo 1: Impulso unitario discreto

clc;
clear;
close all;
 
n = -10:10;
delta = double(n == 0);
 
figure;
stem(n, delta, 'filled', 'LineWidth', 1.3);
grid on;
xlabel('Índice n');
ylabel('Amplitud');
title('Impulso unitario discreto');
ylim([-0.2 1.2]);

Interpretación del Ejemplo 1

La señal impulso unitario discreto tiene valor igual a 1 únicamente en n = 0 y valor igual a 0 en los demás instantes. Esta señal se utiliza para construir secuencias, analizar respuestas al impulso y estudiar sistemas lineales invariantes en el tiempo.

3.3 Impulso unitario desplazado

Un impulso desplazado se representa como delta[n - n0]. El impulso ocurre en el instante n = n0.
Si n0 es positivo, el impulso se desplaza hacia la derecha. Si n0 es negativo, se desplaza hacia la izquierda.

Ejemplo 2: Impulso unitario desplazado

clc;
clear;
close all;
 
n = -10:10;
n0 = 4;
delta_desplazado = double(n == n0);
 
figure;
stem(n, delta_desplazado, 'filled', 'LineWidth', 1.3);
grid on;
xlabel('Índice n');
ylabel('Amplitud');
title('Impulso unitario desplazado en n = 4');
ylim([-0.2 1.2]);

3.4 Señal escalón unitario

En tiempo discreto, el escalón unitario se define como una señal que vale 1 para n >= 0 y 0 para n < 0.
En tiempo continuo, se representa como u(t) y cambia de 0 a 1 en t = 0. El escalón es útil para modelar activaciones, encendidos, cambios bruscos, señales de control y entradas aplicadas a sistemas.

Ejemplo 3: Escalón unitario discreto

clc;
clear;
close all;
 
n = -10:10;
u = double(n >= 0);
 
figure;
stem(n, u, 'filled', 'LineWidth', 1.3);
grid on;
xlabel('Índice n');
ylabel('Amplitud');
title('Escalón unitario discreto u[n]');
ylim([-0.2 1.2]);

Ejemplo 4: Escalón unitario continuo aproximado

clc;
clear;
close all;
 
t = -2:0.001:2;
u_t = double(t >= 0);
 
figure;
plot(t, u_t, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo t [s]');
ylabel('Amplitud');
title('Escalón unitario continuo aproximado u(t)');
ylim([-0.2 1.2]);

Interpretación del escalón unitario

El escalón unitario representa una transición abrupta desde 0 hacia 1. En ingeniería puede representar el encendido de un interruptor, la activación de una fuente, el inicio de una transmisión o la aplicación repentina de una entrada a un sistema dinámico.

3.5 Señal rampa unitaria

La señal rampa discreta puede definirse como r[n] = n u[n].
En tiempo continuo puede representarse como r(t) = t u(t).
La rampa representa una señal que crece linealmente desde el origen. Se utiliza para modelar desplazamientos, incrementos progresivos, señales de referencia y entradas de prueba en sistemas de control.

Ejemplo 5: Rampa unitaria discreta

clc;
clear;
close all;
 
n = -10:10;
u = double(n >= 0);
r = n .* u;
 
figure;
stem(n, r, 'filled', 'LineWidth', 1.3);
grid on;
xlabel('Índice n');
ylabel('Amplitud');
title('Rampa unitaria discreta r[n] = n u[n]');

Ejemplo 6: Rampa unitaria continua aproximada

clc;
clear;
close all;
 
t = -2:0.001:2;
u_t = double(t >= 0);
r_t = t .* u_t;
 
figure;
plot(t, r_t, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo t [s]');
ylabel('Amplitud');
title('Rampa unitaria continua aproximada r(t) = t u(t)');

3.6 Señales exponenciales reales

Una señal exponencial real continua puede expresarse como x(t) = A e^(a t).
Si a < 0, la señal decrece con el tiempo. Si a > 0, la señal crece con el tiempo. Si a = 0, la señal se mantiene constante.
En sistemas físicos, las exponenciales decrecientes aparecen en descarga de capacitores, respuesta natural de circuitos, amortiguamiento mecánico y procesos térmicos.

Ejemplo 7: Exponencial creciente y decreciente

clc;
clear;
close all;
 
t = 0:0.001:3;
 
x_creciente = exp(1.2*t);
x_decreciente = exp(-1.2*t);
 
figure;
 
subplot(2,1,1);
plot(t, x_creciente, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Señal exponencial creciente');
 
subplot(2,1,2);
plot(t, x_decreciente, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Señal exponencial decreciente');

3.7 Señal exponencial discreta

Una señal exponencial discreta puede expresarse como x[n] = A a^n.
Si a < 1, la señal decrece. Si a > 1, la señal crece. Si a es negativo, la señal alterna de signo.

Ejemplo 8: Exponenciales discretas

clc;
clear;
close all;
 
n = 0:20;
 
x1 = (0.8).^n;
x2 = (-0.8).^n;
 
figure;
 
subplot(2,1,1);
stem(n, x1, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('Índice n');
ylabel('Amplitud');
title('Exponencial discreta decreciente x[n] = (0.8)^n');
 
subplot(2,1,2);
stem(n, x2, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('Índice n');
ylabel('Amplitud');
title('Exponencial discreta alternante x[n] = (-0.8)^n');

3.8 Señales sinusoidales

Una señal sinusoidal continua puede expresarse como:
x(t) = A sin(2*pi*f*t + phi)
donde A es la amplitud, f es la frecuencia en Hz y phi es la fase inicial.
Las señales sinusoidales son fundamentales en el análisis frecuencial, telecomunicaciones, corriente alterna, audio, vibraciones y sistemas periódicos.

Ejemplo 9: Señal sinusoidal continua

clc;
clear;
close all;
 
A = 2;
f = 4;
phi = pi/4;
t = 0:0.001:1;
 
x = A*sin(2*pi*f*t + phi);
 
figure;
plot(t, x, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Señal sinusoidal continua x(t) = A sin(2πft + φ)');

Ejemplo 10: Efecto de amplitud, frecuencia y fase

clc;
clear;
close all;
 
t = 0:0.001:1;
 
x1 = sin(2*pi*3*t);
x2 = 2*sin(2*pi*3*t);
x3 = sin(2*pi*8*t);
x4 = sin(2*pi*3*t + pi/3);
 
figure;
 
subplot(4,1,1);
plot(t, x1, 'LineWidth', 1.3);
grid on;
title('Señal base');
 
subplot(4,1,2);
plot(t, x2, 'LineWidth', 1.3);
grid on;
title('Cambio de amplitud');
 
subplot(4,1,3);
plot(t, x3, 'LineWidth', 1.3);
grid on;
title('Cambio de frecuencia');
 
subplot(4,1,4);
plot(t, x4, 'LineWidth', 1.3);
grid on;
title('Cambio de fase');
xlabel('Tiempo [s]');

3.9 Señal sinusoidal discreta

Una señal sinusoidal discreta se expresa como x[n] = A sin(omega n + phi), donde omega es la frecuencia angular discreta en radianes por muestra.
Es importante recordar que en señales discretas la frecuencia se interpreta respecto a la frecuencia de muestreo.

Ejemplo 11: Señal sinusoidal discreta

clc;
clear;
close all;
 
n = 0:40;
A = 1;
omega = pi/5;
phi = 0;
 
x = A*sin(omega*n + phi);
 
figure;
stem(n, x, 'filled', 'LineWidth', 1.2);
grid on;
xlabel('Índice n');
ylabel('Amplitud');
title('Señal sinusoidal discreta x[n] = A sin(omega n + phi)');

3.10 Señales rectangulares

Una señal rectangular toma dos niveles principales de amplitud y se utiliza para representar pulsos, señales digitales, trenes de bits, conmutación y señales de reloj.
En sistemas digitales, las señales rectangulares son esenciales porque permiten representar estados lógicos.

Ejemplo 12: Señal rectangular

clc;
clear;
close all;
 
t = 0:0.001:2;
f = 2;
 
x_rect = sign(sin(2*pi*f*t));
 
figure;
plot(t, x_rect, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Señal rectangular');

3.11 Señales triangulares

Una señal triangular presenta crecimiento y decrecimiento lineal de forma periódica. Se utiliza en modulación, generación de señales de prueba, control por PWM y análisis de sistemas periódicos no sinusoidales.

Ejemplo 13: Señal triangular

clc;
clear;
close all;
 
t = 0:0.001:2;
f = 2;
 
x_tri = 2*abs(2*(f*t - floor(f*t + 0.5))) - 1;
 
figure;
plot(t, x_tri, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Señal triangular aproximada');

3.12 Aplicación en telecomunicaciones

Las señales elementales aparecen constantemente en telecomunicaciones:
  • Las sinusoidales representan portadoras.
  • Los pulsos rectangulares representan bits digitales.
  • Las exponenciales modelan atenuación o respuesta transitoria.
  • El impulso permite analizar la respuesta de un canal.
  • El escalón puede representar la activación de una transmisión.
Comprender estas señales permite interpretar sistemas de transmisión, filtros, modulación, ruido, muestreo y procesamiento digital.

Ejemplo 14: Tren de pulsos digitales

clc;
clear;
close all;
 
bits = [1 0 1 1 0 0 1 0];
muestras_por_bit = 100;
 
senal_digital = repelem(bits, muestras_por_bit);
t = linspace(0, length(bits), length(senal_digital));
 
figure;
plot(t, senal_digital, 'LineWidth', 1.5);
grid on;
xlabel('Tiempo normalizado');
ylabel('Nivel lógico');
title('Tren de pulsos digitales');
ylim([-0.2 1.2]);

Interpretación del tren de pulsos digitales

El tren de pulsos representa una secuencia binaria transmitida como niveles lógicos. En una aplicación real, esta señal podría corresponder a datos digitales enviados por un canal de comunicación, una interfaz serial o un sistema embebido.
La forma rectangular de los pulsos facilita la identificación de los estados lógicos 0 y 1, aunque en canales reales pueden aparecer ruido, atenuación y distorsión.

Conclusiones

Las señales elementales permiten construir y analizar señales más complejas. El impulso, el escalón, la rampa, las exponenciales, las sinusoidales y las señales rectangulares son modelos básicos utilizados ampliamente en ingeniería.
El uso de MATLAB Live Script facilita la representación gráfica de estas señales y permite comprender sus características principales mediante simulación. Esta base será necesaria para estudiar operaciones con señales, convolución, sistemas LTI, análisis en frecuencia y transformadas.
