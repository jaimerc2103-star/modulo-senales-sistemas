Capítulo 7. Sistemas lineales invariantes en el tiempo

Resultado de aprendizaje

Al finalizar este capítulo, el estudiante será capaz de reconocer y analizar sistemas lineales invariantes en el tiempo, verificando las propiedades de linealidad e invariancia temporal mediante ejemplos matemáticos y simulaciones en MATLAB Live Script.

7.1 Introducción

Los sistemas lineales invariantes en el tiempo, conocidos como sistemas LTI por sus siglas en inglés, constituyen una de las clases de sistemas más importantes en Señales y Sistemas.
LTI significa:
  • L: Lineal.
  • T: Time.
  • I: Invariant.
En español, un sistema LTI es un sistema lineal e invariante en el tiempo.
Estos sistemas son fundamentales porque pueden analizarse mediante herramientas matemáticas muy poderosas, como:
  • Respuesta al impulso.
  • Convolución.
  • Transformada de Fourier.
  • Transformada de Laplace.
  • Transformada Z.
  • Función de transferencia.
Muchos sistemas reales pueden aproximarse como sistemas LTI dentro de un rango de operación. Por ejemplo, filtros eléctricos, canales de comunicación, sistemas mecánicos de pequeña señal, circuitos RC, sistemas de audio y algoritmos digitales de filtrado.

7.2 Concepto de sistema LTI

Un sistema es LTI si cumple simultáneamente dos propiedades:
1. Linealidad.
2. Invariancia en el tiempo.
Si un sistema no cumple alguna de estas dos propiedades, no puede clasificarse como LTI.
De forma general, un sistema se representa como:
para tiempo continuo, o:
para tiempo discreto.
Para que el sistema sea LTI, la transformación T{ } debe cumplir el principio de superposición y no debe depender explícitamente del tiempo.

Ejemplo 1: Sistema candidato LTI

clc;
clear;
close all;
 
t = 0:0.001:1;
 
% Señal de entrada
x = sin(2*pi*5*t);
 
% Sistema: y(t) = 3x(t)
y = 3*x;
 
figure;
plot(t,x,'LineWidth',1.5);
hold on;
plot(t,y,'--','LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Sistema y(t) = 3x(t)');
legend('Entrada x(t)','Salida y(t)');

Interpretación del Ejemplo 1

El sistema y(t) = 3x(t) multiplica la entrada por una constante.
Este sistema es lineal porque cumple superposición. También es invariante en el tiempo porque su comportamiento no cambia con el tiempo.
Por tanto, puede clasificarse como un sistema LTI.

7.3 Propiedad de linealidad

Un sistema es lineal si cumple el principio de superposición.
Este principio combina dos condiciones:
1. Homogeneidad o escalamiento.
Si x(t) produce y(t), entonces ax(t) debe producir ay(t).
2. Aditividad.
Si x1(t) produce y1(t) y x2(t) produce y2(t), entonces x1(t)+x2(t) debe producir y1(t)+y2(t).
En forma compacta:
Si esta igualdad se cumple para cualquier par de señales x1(t), x2(t) y constantes a, b, el sistema es lineal.

Ejemplo 2: Verificación de linealidad en y(t) = 2x(t)

clc;
clear;
close all;
 
t = 0:0.001:1;
 
% Señales de entrada
x1 = sin(2*pi*3*t);
x2 = cos(2*pi*5*t);
 
% Constantes
a = 2;
b = -1;
 
% Sistema T{x} = 2x
T = @(x) 2*x;
 
% Lado izquierdo: T{a*x1 + b*x2}
lado_izquierdo = T(a*x1 + b*x2);
 
% Lado derecho: a*T{x1} + b*T{x2}
lado_derecho = a*T(x1) + b*T(x2);
 
% Error de comparación
error_linealidad = max(abs(lado_izquierdo - lado_derecho));
 
figure;
plot(t,lado_izquierdo,'LineWidth',1.5);
hold on;
plot(t,lado_derecho,'--','LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title(['Verificación de linealidad. Error máximo = ', num2str(error_linealidad)]);
legend('T{a x_1 + b x_2}','aT{x_1}+bT{x_2}');
 
disp(['Error máximo de linealidad: ', num2str(error_linealidad)]);
Error máximo de linealidad: 0

Interpretación del Ejemplo 2

Las dos curvas coinciden. El error máximo es cero o numéricamente muy cercano a cero.
Esto indica que el sistema cumple el principio de superposición y, por tanto, es lineal.

Ejemplo 3: Verificación de no linealidad en y(t) = x^2(t)

clc;
clear;
close all;
 
t = 0:0.001:1;
 
% Señales de entrada
x1 = sin(2*pi*3*t);
x2 = cos(2*pi*5*t);
 
% Constantes
a = 1;
b = 1;
 
% Sistema no lineal T{x} = x^2
T = @(x) x.^2;
 
% Lado izquierdo
lado_izquierdo = T(a*x1 + b*x2);
 
% Lado derecho
lado_derecho = a*T(x1) + b*T(x2);
 
% Diferencia
diferencia = lado_izquierdo - lado_derecho;
 
figure;
 
subplot(3,1,1);
plot(t,lado_izquierdo,'LineWidth',1.4);
grid on;
title('T{x_1 + x_2}');
ylabel('Amplitud');
 
subplot(3,1,2);
plot(t,lado_derecho,'LineWidth',1.4);
grid on;
title('T{x_1} + T{x_2}');
ylabel('Amplitud');
 
subplot(3,1,3);
plot(t,diferencia,'LineWidth',1.4);
grid on;
title('Diferencia entre ambos resultados');
xlabel('Tiempo [s]');
ylabel('Error');

Interpretación del Ejemplo 3

Las curvas T{x1+x2} y T{x1}+T{x2} no coinciden. Por tanto, el sistema y(t) = x^2(t) no cumple superposición y se clasifica como no lineal.
Los sistemas no lineales aparecen en saturación de amplificadores, sensores con respuesta no proporcional, circuitos con diodos y transistores fuera de zona lineal, mezcladores y ciertos procesos físicos.

7.5 Propiedad de invariancia en el tiempo

Un sistema es invariante en el tiempo si un desplazamiento temporal aplicado a la entrada produce el mismo desplazamiento temporal en la salida.
Si:
x(t) produce y(t)
entonces:
x(t - t0) debe producir y(t - t0)
para cualquier desplazamiento t0.
Esto significa que el sistema se comporta igual sin importar el instante en que se aplique la señal de entrada.
Si el sistema depende explícitamente del tiempo, normalmente será variante en el tiempo.

Ejemplo 4: Sistema invariante en el tiempo y(t) = 2x(t)

clc;
clear;
close all;
 
t = 0:0.001:3;
t0 = 0.5;
 
% Entrada original
x = sin(2*pi*2*t);
 
% Entrada retardada
x_ret = sin(2*pi*2*(t - t0));
x_ret(t < t0) = 0;
 
% Sistema T{x} = 2x
T = @(x) 2*x;
 
% Salida ante entrada retardada
salida_entrada_retardada = T(x_ret);
 
% Salida original retardada
salida_original_retardada = 2*sin(2*pi*2*(t - t0));
salida_original_retardada(t < t0) = 0;
 
% Comparación
error_invariancia = max(abs(salida_entrada_retardada - salida_original_retardada));
 
figure;
plot(t,salida_entrada_retardada,'LineWidth',1.5);
hold on;
plot(t,salida_original_retardada,'--','LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title(['Sistema invariante en el tiempo. Error = ', num2str(error_invariancia)]);
legend('T{x(t-t_0)}','y(t-t_0)');
 
disp(['Error máximo de invariancia temporal: ', num2str(error_invariancia)]);
Error máximo de invariancia temporal: 0

Interpretación del Ejemplo 4

Las curvas coinciden, lo que indica que retardar la entrada produce una salida igualmente retardada.
El sistema y(t) = 2x(t) es invariante en el tiempo.

7.6 Ejemplo de sistema variante en el tiempo

Considere el sistema:
y(t) = t x(t)
Este sistema depende explícitamente de la variable independiente t.
Por esta razón, si se retarda la entrada, la salida no será simplemente una versión retardada de la salida original.
Por tanto, el sistema es variante en el tiempo.

Ejemplo 5: Sistema variante en el tiempo y(t) = t x(t)

clc;
clear;
close all;
 
t = 0:0.001:3;
t0 = 0.5;
 
% Entrada original
x = sin(2*pi*2*t);
 
% Entrada retardada
x_ret = sin(2*pi*2*(t - t0));
x_ret(t < t0) = 0;
 
% Sistema T{x} = t*x(t)
salida_entrada_retardada = t.*x_ret;
 
% Salida original
y = t.*x;
 
% Salida original retardada y(t-t0)
t_shift = t - t0;
salida_original_retardada = t_shift.*sin(2*pi*2*t_shift);
salida_original_retardada(t < t0) = 0;
 
figure;
plot(t,salida_entrada_retardada,'LineWidth',1.5);
hold on;
plot(t,salida_original_retardada,'--','LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Sistema variante en el tiempo: y(t) = t x(t)');
legend('T{x(t-t_0)}','y(t-t_0)');

Interpretación del Ejemplo 5

Las curvas no coinciden. El sistema y(t) = t x(t) depende explícitamente del tiempo, por lo que su comportamiento cambia según el instante en que se aplique la entrada.
Por esta razón, es un sistema variante en el tiempo.

7.7 Importancia de los sistemas LTI

Los sistemas LTI son importantes porque permiten describir la salida del sistema a partir de la entrada y la respuesta al impulso.
En los próximos capítulos se estudiará que, para un sistema LTI:
y(t) = x(t) * h(t)
en tiempo continuo, y:
y[n] = x[n] * h[n]
en tiempo discreto.
El símbolo * representa la operación de convolución.
Esto significa que si se conoce la respuesta al impulso h(t) o h[n], se puede determinar la salida para cualquier entrada.

7.8 Sistemas LTI en tiempo discreto

En tiempo discreto, muchos sistemas LTI se describen mediante ecuaciones en diferencias.
Por ejemplo:
y[n] = 0.5x[n] + 0.5x[n-1]
Este sistema calcula un promedio entre la muestra actual y la muestra anterior. Es un filtro suavizador simple.
Este sistema es:
  • Lineal.
  • Invariante en el tiempo.
  • Causal.
  • Con memoria.
  • Estable.

Ejemplo 6: Sistema discreto LTI suavizador

clc;
clear;
close all;
 
n = 0:50;
 
% Señal discreta con ruido
rng(2);
x = sin(pi*n/8) + 0.3*randn(size(n));
 
% Sistema LTI: promedio de muestra actual y anterior
x_pasada = [0 x(1:end-1)];
y = 0.5*x + 0.5*x_pasada;
 
figure;
 
subplot(2,1,1);
stem(n,x,'filled','LineWidth',1.0);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Entrada x[n] con ruido');
 
subplot(2,1,2);
stem(n,y,'filled','LineWidth',1.0);
grid on;
xlabel('n');
ylabel('Amplitud');
title('Salida y[n] = 0.5x[n] + 0.5x[n-1]');

Interpretación del Ejemplo 6

El sistema suaviza parcialmente la señal porque combina cada muestra con la muestra anterior.
Este tipo de operación corresponde a un filtro digital simple. Es un ejemplo básico de sistema LTI discreto.

7.9 Verificación de linealidad en sistema discreto

Para el sistema:
y[n] = 0.5x[n] + 0.5x[n-1]
se puede verificar la linealidad comparando:
T{a x1[n] + b x2[n]}
con:
aT{x1[n]} + bT{x2[n]}
Si ambas salidas coinciden, el sistema es lineal.

Ejemplo 7: Verificación de linealidad en sistema discreto LTI

clc;
clear;
close all;
 
n = 0:40;
 
x1 = sin(pi*n/6);
x2 = cos(pi*n/8);
 
a = 2;
b = -0.5;
 
% Definición del sistema discreto
sistema = @(x) 0.5*x + 0.5*[0 x(1:end-1)];
 
lado_izquierdo = sistema(a*x1 + b*x2);
lado_derecho = a*sistema(x1) + b*sistema(x2);
 
error_linealidad = max(abs(lado_izquierdo - lado_derecho));
 
figure;
stem(n,lado_izquierdo,'filled','LineWidth',1.0);
hold on;
stem(n,lado_derecho,'LineWidth',1.0);
grid on;
xlabel('n');
ylabel('Amplitud');
title(['Linealidad en sistema discreto. Error = ', num2str(error_linealidad)]);
legend('T{a x_1 + b x_2}','aT{x_1}+bT{x_2}');
 
disp(['Error máximo de linealidad discreta: ', num2str(error_linealidad)]);
Error máximo de linealidad discreta: 4.4409e-16

Interpretación del Ejemplo 7

Las dos salidas coinciden. Esto confirma que el sistema discreto suavizador cumple la propiedad de linealidad.
Al ser además invariante en el tiempo, se clasifica como un sistema LTI discreto.

7.10 Sistemas que no son LTI

No todos los sistemas son LTI. Algunos sistemas pueden ser:
  • Lineales pero variantes en el tiempo.
  • No lineales pero invariantes en el tiempo.
  • No lineales y variantes en el tiempo.
Ejemplos:
1. y(t) = t x(t)
Es lineal, pero variante en el tiempo.
2. y(t) = x^2(t)
Es no lineal, aunque puede ser invariante en el tiempo.
3. y(t) = t x^2(t)
Es no lineal y variante en el tiempo.

Ejemplo 8: Comparación de sistemas LTI y no LTI

clc;
clear;
close all;
 
t = 0:0.001:1;
x = sin(2*pi*5*t);
 
% Sistema LTI
y1 = 2*x;
 
% Sistema lineal variante en el tiempo
y2 = t.*x;
 
% Sistema no lineal
y3 = x.^2;
 
figure;
 
subplot(3,1,1);
plot(t,y1,'LineWidth',1.4);
grid on;
title('Sistema LTI: y(t) = 2x(t)');
ylabel('Amplitud');
 
subplot(3,1,2);
plot(t,y2,'LineWidth',1.4);
grid on;
title('Sistema lineal variante: y(t) = t x(t)');
ylabel('Amplitud');
 
subplot(3,1,3);
plot(t,y3,'LineWidth',1.4);
grid on;
title('Sistema no lineal: y(t) = x^2(t)');
xlabel('Tiempo [s]');
ylabel('Amplitud');

Interpretación del Ejemplo 8

El primer sistema es LTI porque cumple linealidad e invariancia temporal.
El segundo sistema es lineal, pero no es invariante en el tiempo.
El tercer sistema no es lineal, por lo que no puede ser LTI, aunque su comportamiento no dependa explícitamente del tiempo.

7.11 Aplicación en telecomunicaciones

En telecomunicaciones, un canal ideal puede modelarse como un sistema LTI:
y(t) = a x(t - t0)
donde:
  • a representa la atenuación.
  • t0 representa el retardo.
Este sistema es lineal porque la salida es proporcional a la entrada.
También es invariante en el tiempo porque un retardo adicional en la entrada produce el mismo retardo adicional en la salida.
En canales reales pueden aparecer ruido, distorsión no lineal y variación temporal, por lo que el modelo LTI es una aproximación.

Ejemplo 9: Canal LTI ideal con retardo y atenuación

clc;
clear;
close all;
 
t = 0:0.001:2;
 
% Señal transmitida
x = sin(2*pi*6*t);
 
% Canal LTI ideal
a = 0.7;
t0 = 0.2;
 
t_ret = t - t0;
x_ret = sin(2*pi*6*t_ret);
x_ret(t < t0) = 0;
 
y = a*x_ret;
 
figure;
 
subplot(2,1,1);
plot(t,x,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Señal transmitida x(t)');
 
subplot(2,1,2);
plot(t,y,'LineWidth',1.5);
grid on;
xlabel('Tiempo [s]');
ylabel('Amplitud');
title('Señal recibida y(t) = 0.7x(t - 0.2)');

Interpretación del canal LTI

El canal modifica la señal mediante atenuación y retardo, pero no altera su estructura fundamental.
Este tipo de modelo permite estudiar transmisión de señales, respuesta de canales, filtros y sistemas de comunicación en condiciones ideales.

7.12 Relación entre sistemas LTI y convolución

La razón principal por la que los sistemas LTI son tan importantes es que su salida puede calcularse mediante convolución.
En tiempo continuo:
y(t) = x(t) * h(t)
En tiempo discreto:
y[n] = x[n] * h[n]
donde h(t) o h[n] es la respuesta al impulso del sistema.
Por tanto, una vez conocida la respuesta al impulso, se puede determinar la salida ante cualquier entrada.

Conclusiones

Un sistema LTI debe cumplir simultáneamente linealidad e invariancia en el tiempo. La linealidad permite aplicar el principio de superposición, mientras que la invariancia temporal garantiza que el comportamiento del sistema no cambia con el tiempo.
Los sistemas LTI son fundamentales porque su respuesta puede caracterizarse completamente mediante la respuesta al impulso. Esta propiedad conduce directamente al concepto de convolución, que permite calcular la salida del sistema ante cualquier entrada.
MATLAB Live Script facilita la verificación de linealidad e invariancia en el tiempo mediante simulaciones comparativas, lo que permite conectar los conceptos matemáticos con aplicaciones reales en telecomunicaciones, electrónica, control y procesamiento digital de señales.
